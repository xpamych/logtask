# Tray Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить системный трей с навигацией, созданием задачи и настраиваемым закрытием окна в трей.

**Architecture:** Rust-модуль создаёт tray icon/menu и отправляет события во фронтенд. Настройка `closeToTray` читается при close-requested; существующие команды фронтенда обрабатывают открытие журнала и новой задачи.

**Tech Stack:** Tauri 2 `tray-icon`, Rust, SolidJS, TypeScript.

**Spec:** `docs/superpowers/specs/2026-11-07-tray-design.md`

## Global Constraints

- `Ctrl+Q` и пункт «Выход» всегда завершают приложение.
- При недоступном трее запуск продолжается, ошибка только логируется.
- Глобальные горячие клавиши не входят в итерацию.

## Review Focus

- Старый settings.json: `closeToTray` должен быть `true`.
- Выключенная настройка: крестик не должен перехватываться.
- Скрытое/свёрнутое окно: показ из трея включает visible/unminimize/focus.
- Трей недоступен: setup не должен вернуть ошибку запуска.
- Действия до загрузки графа: используются обычные frontend-обработчики и их ошибки, без отдельного состояния в Rust.
