# Системный трей

## Цель
Дать быстрый доступ к Logtask из системного трея и позволить скрывать главное окно без завершения приложения.

## Поведение
- Иконка Logtask всегда доступна, пока запущено приложение. Клик по ней показывает, разворачивает и фокусирует главное окно.
- Меню: «Открыть Logtask», «Сегодняшний журнал», «Новая задача», «Выход».
- «Сегодняшний журнал» и «Новая задача» сначала показывают окно, затем вызывают существующие действия фронтенда через события Tauri.
- Настройка «Скрывать в трей при закрытии» находится в разделе «Внешний вид», включена по умолчанию и сохраняется в `.logtask/settings.json` как `closeToTray`.
- При включённой настройке крестик скрывает окно; при выключенной завершает приложение. `Ctrl+Q` и «Выход» всегда завершают его независимо от настройки.

## Подходы
- **Выбрано: встроенный tray API Tauri.** Feature `tray-icon`, отдельный `src-tauri/src/tray.rs`, menu/tray events и `on_window_event` для close-requested.
- Внешний плагин/helper-процесс отклонён: лишние зависимости и IPC без преимуществ для одного окна.
- Глобальные горячие клавиши не входят в эту итерацию.

## Надёжность
- Если трей недоступен в окружении рабочего стола, приложение продолжает запускаться; ошибка записывается в лог.
- Состояние трея удерживается до завершения приложения, повторный показ окна идемпотентен.
- Старые настройки без `closeToTray` читаются со значением `true`.

## Проверка
Rust-тесты настроек и маршрутизации tray-действий, frontend typecheck/тесты, полный Rust suite, clippy/fmt/build. Ручной сценарий на Linux: меню, клик, обе настройки закрытия, Ctrl+Q и запуск окружения без трея.
