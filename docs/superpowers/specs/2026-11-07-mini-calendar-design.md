# Мини-календарь журнала

## Цель
Компактный календарь в левой панели над «Навигацией» для быстрого перехода к существующим дням журнала.

## Поведение
- Месячная сетка по `weekStart`, стрелки предыдущего/следующего месяца и кнопка «Сегодня».
- Дни с существующим журналом отмечаются точкой и доступны для выбора; дни без журнала неактивны, файлы не создаются.
- Текущая дата выделяется рамкой, выбранная — акцентным фоном.
- Клик/клавиатура загружает нужный день в существующую ленту, прокручивает и подсвечивает его. Ранее загруженные дни и состояние редактирования не теряются.
- Настройка «Показывать мини-календарь» в разделе «Внешний вид», `showCalendar: true` по умолчанию. Старые settings.json получают `true`.

## Подходы
- **Выбрано: в сайдбаре над навигацией.** Не занимает центральную ленту и использует существующие `journalList`/`journalPrev`.
- Над лентой отклонено пользователем: занимает основное пространство.

## Реализация
- Чистый `src/lib/calendar.ts`: модель месяца и календарная арифметика без объектов момента времени. Даты `YYYY_MM_DD` сравниваются строками, вычисления сетки в UTC, локальная дата берётся только из полей `Date`.
- `MiniCalendar.tsx`: нативные `<button>` с доступными именами дат и `aria-pressed` для выбранного дня; стрелки месяца и клавиатурная навигация по сетке.
- `JournalTape`: публичный `openDay(name)`, догрузка существующих страниц порциями до нужной даты, выделение и scrollIntoView.
- `App.tsx`/`Sidebar.tsx`: показ по `settings.showCalendar`, передача выбранной даты через ref или общий signal.
- CSS только в `public/styles/global.css`, обе темы, цели не меньше 24×24 px.

## Проверка
Unit-тесты сетки месяца, високосного февраля, смены года, weekStart, доступных дат и клавиатурной навигации. Frontend typecheck/tests/build, полный Rust suite. Ручной сценарий: отключение настройки, листание месяцев, клик по старому дню, today, недоступные даты, узкая панель и обе темы.
