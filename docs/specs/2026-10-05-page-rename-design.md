# Переименование страниц — дизайн

Дата: 2026-10-05. Статус: утверждено подход «обновлять ссылки, как в Logseq».

## Проблема

Страницу нельзя переименовать из UI: ни заголовок в `PageView`, ни файл
`pages/<имя>.md`. В Logseq переименование также обновляет все ссылки на
страницу — делаем так же, иначе `[[ссылки]]` ломаются (ведут на виртуальную
страницу).

## Решение

Клик по заголовку открытой страницы (не журнала) переводит его в инлайн-редактор;
подтверждение вызывает новую IPC-команду `page_rename`, которая атомарно
переименовывает файл, переписывает ссылки во всех затронутых файлах и
переиндексирует граф — новое имя сразу видно в индексе, поиске, сайдбаре.

## Ядро (Rust)

### `core/rename.rs` (новый модуль)

`pub fn replace_refs(text: &str, old: &str, new: &str) -> String` — чистая
функция текстовой замены ссылок в md-тексте:

- `[[old]]` → `[[new]]`;
- `[[old|псевдоним]]` → `[[new|псевдоним]]` (псевдоним сохраняется);
- `#[[old]]` → `#[[new]]`;
- `#old` → `#new` — только когда `old` без пробелов; граница токена —
  не-буква/не-цифра (чтобы `#ALR` не зацепило `#ALR2`); кириллица —
  буквы (`char::is_alphanumeric` + `-`/`_` внутри токена).

Замена работает посимвольным сканированием (без regex-зависимости).
Покрывается unit-тестами: простые ссылки, псевдонимы, теги, границы токенов,
отсутствие ложных срабатываний (`[[old2]]`, `#old2`, часть слова).

### `Graph::rename_page(old, new, root)` в `core/index.rs`

1. Валидация: страница `old` существует и не журнал (`PageKind::Journal`);
   `new` непустое, без `/` и `\`, без ведущих/хвостовых пробелов;
   страница `new` не существует в индексе и файла `pages/<new>.md` нет.
   Ошибки — `Err` с русским текстом.
2. `std::fs::rename(pages/<old>.md, pages/<new>.md)`.
3. Затронутые страницы: из `backlinks` по `old` + сама страница
   (self-ссылки). Для каждой: читается файл, `replace_refs(text, old, new)`,
   при изменении — `atomic_write` (существующий `fswrite`).
4. Индекс внутри `rename_page` не перестраивается — перестройка и событие
   `graph-changed` идут через существующий `watcher::reindex_and_emit`
   в IPC-команде (полная перезагрузка с диска, ~72 мс — в бюджете).
5. Возвращает `Ok(())`.

### IPC

- `commands.rs`: `page_rename(old_name, new_name, app, state) ->
  Result<(), String>` — прогон `Graph::rename_page` под write-локом,
  `mark_self_write`, затем `watcher::reindex_and_emit(&app)` (перечитывает
  граф с диска и шлёт `graph-changed` — новое имя сразу в индексе, поиске
  и сайдбаре).
- Регистрация в `invoke_handler!` в `lib.rs`.
- Обёртка `pageRename(oldName, newName)` в `src/lib/api.ts`.

## Фронтенд

### `PageView.tsx`

- Заголовок страницы (`kind === "page"`, не журнал) становится кликабельным:
  клик → `<input class="page-title-input">` с текущим именем, autofocus,
  выделение всего текста.
- Enter / blur — подтвердить; Escape — отмена. Пустое или неизменное имя —
  без вызова.
- Во время запроса input disabled; ошибка — `.error` рядом, остаёмся в
  режиме редактирования.
- После успеха: `onRename(newName)` в App — навигация на новое имя
  (`openPage(newName)`), обновление `favorites` в настройках (старое имя →
  новое) и `recentPages` в localStorage.
- Журналы не переименовываются (заголовок даты без редактирования).

### Стили

`global.css`: `.page-title-input` — шрифт/размер как у `.page-title`,
минимальная рамка.

## Что НЕ делаем (YAGNI)

- Namespaced-страницы (`Foo___Bar`, маппинг `/`) — как и раньше, не
  поддерживаются; запрет `/` в новом имени это фиксирует.
- Переименование виртуальных страниц (без файла).
- Обновление `((uuid))`-рефов (они по uuid, не ломаются).
- Случай одновременной внешней правки затронутого файла: mtime-проверка
  пропускается (файл перечитывается с диска перед заменой); конфликт с
  Syncthing в окне между чтением и записью принимаем как есть — окно
  миллисекундное, а `atomic_write` гарантирует целостность файла.
