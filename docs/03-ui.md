# Интерфейс

## Стартовое окно (layout как у Logseq)
```
┌─────────────────────────────────────────────────────────────┐
│ ◧  [ поиск… ]                    ◨        —  ▢  ✕ (topbar)  │
├────────────┬───────────────────────────────┬────────────────┤
│ Граф ▾     │ Лента журнала / страница /    │ Панель задач   │
│ Навигация  │ все страницы                  │ (канбан /      │
│ • Журналы  │ ┌─── 29 сен 2026 (сегодня) ─┐ │  матрица /     │
│ • Все стр. │ │  - ...блоки...            │ │  запросы)      │
│ Избранное  │ ├─── 28 сен 2026 ──────────┤ │                │
│ Недавнее   │ └────────────────────────────┘ │                │
└────────────┴───────────────────────────────┴────────────────┘
```
- **Верхняя полоса (topbar)**: слева кнопка сворачивания левой панели,
  кнопки навигации «← назад / → вперёд» (история видов: журнал, задачи,
  все страницы, открытые страницы — как в браузере; дублируется боковыми
  кнопками мыши «назад/вперёд») и «домой» (ведёт на домашний вид
  из настройки `homeView`, по умолчанию — журналы) и «синхронизация»
  (иконки — инлайн-SVG в стиле Lucide, `src/components/icons.tsx`)
  (ручной запуск синка интеграций, во время синка крутится, бейдж — число
  конфликтов), по
  центру — строка поиска по страницам и блокам (результаты выпадающим
  списком, Escape/выбор очищает запрос), справа — кнопка правой панели и
  кнопки управления окном (свернуть/развернуть/закрыть). Полоса — область
  перетаскивания окна. Системная рамка окна выключена по умолчанию
  (`decorations: false`); включается настройкой `systemTitlebar`
  (чекбокс «Системная рамка окна» в настройках) — тогда кнопки управления
  окном скрываются, рамкой управляет ОС.
- **Сайдбар**: переключатель графов (название текущего, по клику меню:
  «Добавить граф…» + список недавних с кнопкой ✕ у каждого — убирает граф
  из списка; удаление текущего закрывает его и возвращает на экран
  приветствия, файлы не трогаются), меню «Навигация» (Журналы — лента;
  Задачи — страница задач с режимами Канбан/Матрица/Подборки;
  Все страницы — список в центре со звёздочками), секции «Избранное»
  (страницы со звёздочкой, хранятся в `settings.json` графа,
  `favorites: string[]`) и «Недавнее» (последние 10 открытых страниц,
  localStorage).
- Центр — лента дней: «сегодня» сверху, скролл вниз подгружает предыдущие
  дни (`journal_prev`). Между ними — разделители-даты, как в Logseq.
  Также в центре открываются страница «Задачи», вид «Все страницы»
  и отдельные страницы графа.
- Правая панель — **контекстная**: инструменты, зависящие от того, что
  открыто в центре. Сейчас там вкладка «Оглавление»: markdown-заголовки
  (`#`..`######`) открытой страницы с отступами по уровню, клик по строке —
  переход к блоку с заголовком (с подсветкой). В режиме журнала —
  заголовки сегодняшнего дня. Дальше — вкладка с визуальным графом и т.п.
- Обе боковые панели ресайзятся перетаскиванием ручки-разделителя
  (`PanelResizer`, 180–480 px) и сворачиваются кнопками в topbar;
  ширины сохраняются в настройках графа и восстанавливаются при следующем
  запуске.
- Если граф не выбран (первый запуск), вместо layout показывается
  приветственный экран: логотип, краткое описание и две кнопки —
  «Выбрать папку графа» (существующий граф) и «Создать новый граф»
  (scaffold: в выбранной папке создаются пустые `journals/` и `pages/`).
  Если при выборе папки в ней нет ни `journals/`, ни `pages/`, приложение
  предлагает создать там новый граф (confirm). После выбора граф запоминается
  и дальше открывается автоматически.

## 1. Лента журнала
- Блоки редактируются прямо в ленте: клик по тексту → `<textarea>`,
  сохранение по blur или `mod+Enter`, отмена по Escape. При наборе `[[` —
  мгновенное автодополнение страниц. Backspace в самом начале блока
  склеивает его с вышестоящим, Delete в конце текста приклеивает
  нижестоящий, Tab делает блок ребёнком предыдущего соседа, Shift+Tab
  поднимает на уровень родителя (как в Logseq); редактирование продолжается
  в том же блоке с курсором на месте. Редактор — весь блок целиком (как в
  Logseq): первая строка с опциональным `[#A]/[#B]/[#C]`, дальше —
  строки-продолжения (параграфы, код, свойства `key:: value`,
  `:LOGBOOK:`/`CLOCK:`); Enter переводит строку. При сохранении блок
  перепарсивается: маркер приоритета уходит в модель, свойства и логбук
  распознаются, остальное пишется как сырые строки с отступом
  «отступ блока + 2 пробела».
- Слева у блока один кружок: цвет — по статусу, внутри — значок приоритета
  (↑ красная, – зелёное, ↓ серая), если приоритет задан. У блоков без
  статуса — полый кружок (со значком приоритета цвета приоритета, если он
  есть). Клик по кружку открывает мини-попап, где меняются и статус
  (список с цветными точками), и приоритет (↑ высокий / – средний /
  ↓ низкий / «убрать приоритет»). Остальное меняется
  через меню быстрого редактирования: `mod+enter` на блоке или кнопка меню
  (срочно/важно/приоритет/deadline/CLOCK/статус).
- В пустом дне клик по «В этот день записей нет» открывает инлайн-редактор
  новой записи: Enter — сохранить блок, Escape — отмена.
- `scheduled`/`deadline` рисуются датой справа от блока; просрочка — красным.
- Идёт отсчёт CLOCK — на блоке виден индикатор часов.
- Если во время редактирования блока приходит `graph-changed`, обновление
  вида откладывается до сохранения блока (черновик не затирается).
- Мини-календарь навигации по дням — не реализован, план (фаза 7).

## 2. Страница «Задачи»
Две вкладки (выбор запоминается в localStorage):
- **Подборки** (по умолчанию) — сворачиваемые группы-сохранённые фильтры,
  как `:default-queries` на домашней странице Logseq: у группы счётчик
  задач справа, у задачи — кружок статуса/приоритета с общим мини-попапом
  (как в ленте), первая строка текста, страница-источник справа в шапке
  (при нехватке ширины ужимается с многоточием) и свойства блока
  (source-id, author, url…, из `props` в `TaskDto`).
- **Доска** — канбан или матрица Эйзенхауэра; представление переключается
  сегмент-кнопкой внутри вкладки и тоже запоминается
  (`logtask:boardView`).

### Канбан
Доска колонок по статусам: Бэклог / К выполнению / В работе / На проверке /
Выполнено / Отменено. Раскладка адаптивная (CSS grid, колонки ~260px):
сколько колонок влезает по ширине панели — столько и показывается в ряд,
на узкой панели колонки складываются друг под другом.
- Карточка задачи везде одна (канбан/матрица/подборки): кружок
  статуса/приоритета с общим мини-попапом, первая строка текста,
  страница-источник справа в шапке (ужимается с многоточием), флаги
  срочности/важности и дедлайн. В подборках дополнительно — таблица
  свойств блока. Клик по тексту — инлайн-редактор блока прямо в карточке
  (blur/Ctrl+Enter — сохранить, Escape — отмена); переход к файлу — только
  по клику на имя страницы справа; правый клик — контекстное меню
  (статус/приоритет/срочность/важность/дедлайн/удалить блок).
  Если у задачи есть вложенные задачи — под ней прогресс-бар с сегментами
  по цветам их статусов и кнопка `▸ N/M`, раскрывающая вложенные карточки;
  в выдачу подборок/канбана/матрицы попадают только верхнеуровневые задачи
  (вложенные — внутри родителя, без дублирования).
- Drag&drop между колонками меняет маркер статуса; клик на имя страницы —
  переход к блоку в ленте (с подсветкой).
- Фильтры: поиск по тексту, страница, «скрыть выполненные». Состояние фильтров
  запоминается (localStorage).

### Матрица Эйзенхауэра
```
         срочно            несрочно
важно   ┌──────────────┬──────────────┐
        │ I Сделать    │ II Заплан-ть │
        ├──────────────┼──────────────┤
        │ III Делегир. │ IV Выкинуть  │
        └──────────────┴──────────────┘
```
- Перетаскивание карточки между клетками = установка `urgency`/`importance`
  (свойства пишутся в файл, квадрант пересчитывается).
- Цвет задачи — по приоритету, показываются флаги срочности/важности и дата
  (статус и приоритет — в кружке карточки, как везде).
- Внутри клетки — сортировка по приоритету, затем по странице; лимит
  видимых карточек (развёртка по клику).

## 4. Подборки задач (замена `:default-queries`)
Режим «Подборки» на странице «Задачи»: сохранённые именованные фильтры,
каждый всегда показывает актуальный список задач по своим условиям.
Формат — простой JSON в `.logtask/queries.json` (массив, camelCase):
```json
[
  { "title": "Сейчас",
    "filter": { "status": ["DOING", "TODO"] },
    "sort": ["priority"], "collapsed": false },
  { "title": "Проекты", "filter": { "page": "Проекты - TODO" }, "collapsed": true },
  { "title": "Репозитории",
    "filter": { "pagePrefix": "Репозиторий -" }, "collapsed": true }
]
```
- В заголовке подборки видно человекочитаемое описание фильтра
  («открытые · В работе · страница начинается с "Проект"») и число задач.
- Пустое состояние предлагает шаблоны одним кликом («Сейчас в работе»,
  «Бэклог», «Всё открытое»).
- Редактор подборки: название, «только незавершённые», статусы, страница
  (точно / начинается с / скрыть), теги, квадрант матрицы.
- При первом старте подборки импортируются из `:default-queries` твоего
  config.edn (кнопка «⤓ Импорт из Logseq»), дальше редактируются мышкой в UI.

## 5. Страницы, ссылки, обратные ссылки
- Навигация по страницам: поиск в верхней полосе, вид «Все страницы»
  (звёздочка = избранное), секции «Избранное»/«Недавнее» в сайдбаре.
- Переход по `[[ссылке]]`/`#тегу` на страницу без файла открывает
  **виртуальную страницу** (как в Logseq): заголовок, пометка «Страница ещё
  не создана» и секция обратных ссылок — видно, где она упоминается.
- В отображении (лента, карточки задач, поиск, обратные ссылки) `[[ссылки]]`
  и `#теги` показываются **без md-разметки** — как визуальные ссылки
  (`[[Цель|псевдоним]]` → «псевдоним»); разметка видна только в режиме
  редактирования блока.
- Markdown тоже рендерится без разметки (`src/lib/text.ts`, `parseInline` +
  `splitMdBlocks`): `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `` `код` ``,
  `^^подсветка^^`, заголовки `#`–`######` и блоки кода ```` ``` ````.
  Блоки кода — с подсветкой синтаксиса (`lowlight`/highlight.js,
  `src/lib/highlight.ts` + `CodeBlock`): язык из ограждения ```` ```rust ````
  или автоопределение, полностью оффлайн (библиотека в бандле).
  Рендер — только JSX-сегменты, innerHTML не используется.
- Открытая страница: контент + снизу секция **«Ссылки»** (блоки с
  `[[эта страница]]` или `#тегом`), с превью текста и переходом к источнику.
  В заголовке страницы — звёздочка избранного. Клик по заголовку страницы
  (не журнала) — инлайн-переименование: input, Enter/blur — сохранить,
  Escape — отмена; переименовывается файл и переписываются ссылки на
  страницу во всём графе (см. 02-format), имя в избранном и недавних
  подменяется автоматически.
- Автодополнение `[[` по существующим страницам и тегам — мгновенное
  (индекс в памяти).

## Шорткаты
Реализован только `mod+enter` — меню быстрого редактирования блока.
Остальные — план (фаза 7):
| Действие | Клавиша | Статус |
|---|---|---|
| Меню быстрого редактирования блока | `mod+enter` | реализовано |
| Новая задача сегодня | `mod+shift+t` | план (фаза 7) |
| Следующий/предыдущий день | `mod+shift+→` / `mod+shift+←` | план (фаза 7) |
| Панель команд | `mod+k` | план (фаза 7) |
| Переключение правой панели (канбан/матрица/запросы) | `mod+shift+p` | план (фаза 7) |
| Установка срочности | `1`/`2`/`3` (low/medium/high) в меню блока | план (фаза 7) |
| Установка важности | `q`/`w`/`e` в меню блока | план (фаза 7) |
| Календарь дней | `mod+shift+c` | план (фаза 7) |

## Темы и поведение
- Три режима темы: **Системная** (по умолчанию — следует
  `prefers-color-scheme` ОС и переключается на лету через `matchMedia`),
  **Светлая**, **Тёмная**. CSS-переменные (`body.theme-dark` /
  `body.theme-light`, один файл `public/styles/global.css`).
- Палитра (не Logseq): тёмная — фон `#222`/`#2a2a2a`/`#1a1a1a`, акцент
  бирюза `#09bec8`, второй акцент фиолет `#9b59b6`; светлая — фон `#f4f6f7`,
  акцент `#0891a0`, второй `#7d3c98`. Семантические переменные:
  `--success`/`--warning`/`--danger` (`#4caf50`/`#ff9800`/`#f44336`).
  Ссылки и теги — `--accent-2`, акценты и кнопки — `--accent`.
- Сворачивание секций запросов (`collapsed: true/false`) — как сейчас.
- Настройки графа — `<граф>/.logtask/settings.json` (`settings.rs`):
  `theme` (`system` по умолчанию | `dark` | `light`), `fontScale` (0.85…1.4),
  `weekStart` (0 — воскресенье, 1 — понедельник), `kanbanLimit` (задач в
  колонке), `sidebarWidth`/`taskpanelWidth` (ширины панелей, px;
  обновляются после drag ручек), `favorites` (избранные страницы),
  `systemTitlebar` (системная рамка окна, по умолчанию выключена),
  `homeView` (`journal` | `tasks` | `pages` — домашний вид: кнопка «⌂»
  и стартовый экран при открытии графа, по умолчанию `journal`),
  `statuses` — массив
  `{marker, label, color, visible, shortcut}`; порядок массива = порядок
  колонок канбана. Настройки открываются страницей в центре: пункт
  «Настройки» в навигации сайдбара (под «Все страницы»), при открытии под
  ним появляются вложенные разделы — Общие / Внешний вид / Задачи /
  Интеграции; переходы по разделам попадают в историю видов. Сохранение
  автоматическое (дебаунс 400 мс для текстовых полей и слайдера, остальное —
  сразу), состояние — точка у пункта «Настройки»: зелёная — сохранено,
  жёлтая — сохранение, красная — ошибка.
