# Интерфейс

## Стартовое окно (layout как у Logseq)
```
┌────────────┬───────────────────────────────┬──────────────┐
│ Сайдбар    │ Лента журнала                 │ Панель       │
│ • поиск    │ ┌─── 29 сен 2026 (сегодня) ─┐ │ задач        │
│ • Журнал   │ │  - ...блоки...            │ │ (канбан /    │
│   (последн.)│ │  - ...                    │ │  матрица /   │
│ • Страницы │ ├─── 28 сен 2026 ──────────┤ │  запросы)    │
│   (список) │ │  - ...                    │ │              │
│            │ └────────────────────────────┘ │              │
└────────────┴───────────────────────────────┴──────────────┘
```
- Центр — сверху строка **поиска** по страницам и блокам (результаты
  выпадающим списком, Escape/выбор очищает запрос), под ней лента дней:
  «сегодня» сверху, скролл вниз подгружает предыдущие дни (`journal_prev`).
  Между ними — разделители-даты, как в Logseq.
- Сайдбар — вверху переключатель графов: название текущего графа, по клику
  выпадающее меню: первое действие «Добавить граф…» (диалог выбора папки),
  ниже список недавних графов для переключения. Далее статистика графа,
  страницы, журналы.
- Правая панель — вкладки: **Канбан**, **Матрица**, **Мои запросы**
  (настраиваемый список задач). Переключение мышью (шорткаты — фаза 7).
- Обе боковые панели ресайзятся перетаскиванием ручки-разделителя
  (`PanelResizer`, 180–480 px); ширины сохраняются в настройках графа и
  восстанавливаются при следующем запуске.
- Если граф не выбран (первый запуск), вместо layout показывается
  приветственный экран: логотип, короткое описание и кнопка «Выбрать папку
  графа» (диалог выбора каталога). После выбора граф запоминается и дальше
  открывается автоматически.

## 1. Лента журнала
- Блоки редактируются прямо в ленте: двойной клик по тексту → `<textarea>`,
  сохранение по Enter/blur, отмена по Escape. При наборе `[[` — мгновенное
  автодополнение страниц.
- У блоков-задач слева цветной кружок-статус (индикатор); статус и всё
  остальное меняется через меню быстрого редактирования: `mod+enter` на
  блоке или кнопка меню (срочно/важно/приоритет/deadline/CLOCK/статус).
- `scheduled`/`deadline` рисуются датой справа от блока; просрочка — красным.
- Идёт отсчёт CLOCK — на блоке виден индикатор часов.
- Если во время редактирования блока приходит `graph-changed`, обновление
  вида откладывается до сохранения блока (черновик не затирается).
- Мини-календарь навигации по дням — не реализован, план (фаза 7).

## 2. Канбан (список задач)
Доска колонок по статусам: Бэклог / К выполнению / В работе / На проверке /
Выполнено / Отменено.
- Карточка = задача: текст, тег страницы-источника, приоритет, даты.
- Drag&drop между колонками меняет маркер статуса; клик на карточку — переход
  к блоку в ленте (с подсветкой).
- Фильтры: поиск по тексту, страница, «скрыть выполненные». Состояние фильтров
  запоминается (localStorage).

## 3. Матрица Эйзенхауэра
```
         срочно            несрочно
важно   ┌──────────────┬──────────────┐
        │ I Сделать    │ II Заплан-ть │
        ├──────────────┼──────────────┤
        │ III Делегир. │ IV Выкинуть  │
        └──────────────┴──────────────┘
```
- Перетаскивание карточки между клетками = установка `urgency`/`importance`
  (свойства пишутся в файл, квадрант пересчитывается).
- Цвет задачи — по приоритету, показываются флаги срочности/важности и дата.
- Внутри клетки — сортировка по приоритету, затем по странице; лимит
  видимых карточек (развёртка по клику).

## 4. Мои запросы (замена `:default-queries`)
Вкладка с настраиваемыми группами задач; формат — простой JSON в
`.logtask/queries.json` (массив запросов, camelCase):
```json
[
  { "title": "Сейчас",
    "filter": { "status": ["DOING", "TODO"] },
    "sort": ["priority"], "collapsed": false },
  { "title": "Проекты", "filter": { "page": "Проекты - TODO" }, "collapsed": true },
  { "title": "Репозитории",
    "filter": { "pagePrefix": "Репозиторий -" }, "collapsed": true }
]
```
При первом старте они импортируются из `:default-queries` твоего config.edn
(«Сейчас / Проекты / Остальные дела»), дальше редактируются
мышкой в UI.

## 5. Страницы, ссылки, обратные ссылки
- Дерево страниц слева + поиск (как logseq-awesome-links, только встроено).
- Открытая страница: контент + снизу секция **«Ссылки»** (блоки с
  `[[эта страница]]` или `#тегом`), с превью текста и переходом к источнику.
- Автодополнение `[[` по существующим страницам и тегам — мгновенное
  (индекс в памяти).

## Шорткаты
Реализован только `mod+enter` — меню быстрого редактирования блока.
Остальные — план (фаза 7):
| Действие | Клавиша | Статус |
|---|---|---|
| Меню быстрого редактирования блока | `mod+enter` | реализовано |
| Новая задача сегодня | `mod+shift+t` | план (фаза 7) |
| Следующий/предыдущий день | `mod+shift+→` / `mod+shift+←` | план (фаза 7) |
| Панель команд | `mod+k` | план (фаза 7) |
| Переключение правой панели (канбан/матрица/запросы) | `mod+shift+p` | план (фаза 7) |
| Установка срочности | `1`/`2`/`3` (low/medium/high) в меню блока | план (фаза 7) |
| Установка важности | `q`/`w`/`e` в меню блока | план (фаза 7) |
| Календарь дней | `mod+shift+c` | план (фаза 7) |

## Темы и поведение
- Три режима темы: **Системная** (по умолчанию — следует
  `prefers-color-scheme` ОС и переключается на лету через `matchMedia`),
  **Светлая**, **Тёмная**. CSS-переменные (`body.theme-dark` /
  `body.theme-light`, один файл `public/styles/global.css`).
- Палитра (не Logseq): тёмная — фон `#222`/`#2a2a2a`/`#1a1a1a`, акцент
  бирюза `#09bec8`, второй акцент фиолет `#9b59b6`; светлая — фон `#f4f6f7`,
  акцент `#0891a0`, второй `#7d3c98`. Семантические переменные:
  `--success`/`--warning`/`--danger` (`#4caf50`/`#ff9800`/`#f44336`).
  Ссылки и теги — `--accent-2`, акценты и кнопки — `--accent`.
- Сворачивание секций запросов (`collapsed: true/false`) — как сейчас.
- Настройки графа — `<граф>/.logtask/settings.json` (`settings.rs`):
  `theme` (`system` по умолчанию | `dark` | `light`), `fontScale` (0.85…1.4),
  `weekStart` (0 — воскресенье, 1 — понедельник), `kanbanLimit` (задач в
  колонке), `sidebarWidth`/`taskpanelWidth` (ширины панелей, px;
  обновляются после drag ручек), `statuses` — массив
  `{marker, label, color, visible, shortcut}`; порядок массива = порядок
  колонок канбана. Редактируются из модалки настроек в UI.
