# Интерфейс

## Стартовое окно (layout как у Logseq)
```
┌────────────┬───────────────────────────────┬──────────────┐
│ Сайдбар    │ Лента журнала                 │ Панель       │
│ • поиск    │ ┌─── 29 сен 2026 (сегодня) ─┐ │ задач        │
│ • Избранное│ │  - ...блоки...            │ │ (канбан /    │
│ • Журнал   │ │  - ...                    │ │  матрица /   │
│   (календ.)│ ├─── 28 сен 2026 ──────────┤ │  запросы)    │
│ • Страницы │ │  - ...                    │ │              │
│   (дерево) │ └────────────────────────────┘ │              │
└────────────┴───────────────────────────────┴──────────────┘
```
- Центр — лента дней: «сегодня» сверху, скролл вниз подгружает предыдущие
  дни (`journal_prev`). Между ними — разделители-даты, как в Logseq.
- Правая панель — вкладки: **Канбан**, **Матрица**, **Мои запросы**
  (настраиваемый список задач). Переключение мышью и шорткатами.

## 1. Лента журнала
- Блоки редактируются прямо в ленте (contenteditable), без перехода в режим.
- У блоков-задач слева цветной кружок-статус; клик циклит статусы,
  `mod+enter` — открыть быстрое меню (срочно/важно/приоритет/deadline).
- `scheduled`/`deadline` рисуются датой справа от блока; просрочка — красным.
- Сверху над «сегодня» — нативный мини-календарь (`logseq-journals-calendar`
  встроен): навигация по дням, первое число недели — понедельник
  (у тебя firstDayOfWeek: 1).

## 2. Канбан (список задач)
Доска колонок по статусам: Бэклог / К выполнению / В работе / На проверке /
Выполнено / Отменено.
- Карточка = задача: текст, тег страницы-источника, приоритет, даты.
- Drag&drop между колонками меняет маркер статуса; клик на карточку — переход
  к блоку в ленте (с подсветкой).
- Фильтры: статус/тег/страница/дата; сортировка — по приоритету, срочности,
  дате. Состояние фильтров запоминается.

## 3. Матрица Эйзенхауэра
```
         срочно            несрочно
важно   ┌──────────────┬──────────────┐
        │ I Сделать    │ II Заплан-ть │
        ├──────────────┼──────────────┤
        │ III Делегир. │ IV Выкинуть  │
        └──────────────┴──────────────┘
```
- Перетаскивание карточки между клетками = установка `urgency`/`importance`
  (свойства пишутся в файл, квадрант пересчитывается).
- Цвет задачи — по приоритету, размер/яркость — по близости deadline.
- Внутри клетки — сортировка по deadline, лимит видимых карточек
  (развёртка по клику).

## 4. Мои запросы (замена `:default-queries`)
Вкладка с настраиваемыми группами задач; формат — простой JSON в
`.logtask/settings.json`:
```json
"queries": [
  { "title": "Сейчас",
    "filter": { "status": ["DOING", "TODO"], "open": true },
    "sort": ["urgency", "importance"] },
  { "title": "Работа", "filter": { "page": "Пример - TODO" }, "collapsed": true },
  { "title": "Gitea",
    "filter": { "pagePrefix": "Gitea -" }, "collapsed": true }
]
```
При первом старте они импортируются из `:default-queries` твоего config.edn
(«Сейчас / Работа / PPDB / Gitea / Остальные дела»), дальше редактируются
мышкой в UI.

## 5. Страницы, ссылки, обратные ссылки
- Дерево страниц слева + поиск (как logseq-awesome-links, только встроено).
- Открытая страница: контент + снизу секция **«Ссылки»** (блоки с
  `[[эта страница]]` или `#тегом`), с превью текста и переходом к источнику.
- Автодополнение `[[` по существующим страницам и тегам — мгновенное
  (индекс в памяти).

## Шорткаты (дефолты, переназначаются)
| Действие | Клавиша |
|---|---|
| Новая задача сегодня | `mod+shift+t` (как у тебя в todo-plugin) |
| Цикл статуса блока | `mod+enter` |
| Следующий/предыдущий день | `mod+shift+→` / `mod+shift+←` (твои) |
| Панель команд | `mod+k` |
| Переключение правой панели (канбан/матрица/запросы) | `mod+shift+p` |
| Установка срочности | `1`/`2`/`3` (low/medium/high) в меню блока |
| Установка важности | `q`/`w`/`e` в меню блока |
| Календарь дней | `mod+shift+c` |

## Темы и поведение
- Светлая/тёмная тема + CSS-переменные (сегодня тёмная `#023643`-палитра из
  настроек logseq-todo-plugin — унаследуем как одну из предустановок).
- Анимации минимальны (`killAnimations: true` у тебя уже стоит — совпадает).
- Сворачивание секций задач (`collapsed: true/false`) — как сейчас.
