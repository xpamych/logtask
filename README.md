# Logtask — быстрая записная книжка с задачами как у Logseq, только лёгкая

Назначение: десктоп-приложение для заметок по дням + управления задачами,
работающее напрямую с папкой `.md`-файлов (формат Logseq). Без Electron,
без SQLite, без плагинов и без секунд на запуск.




## Что перенято у Logseq
- Главное окно — лента журнальных страниц по дням (`journals/yyyy_MM_dd.md`),
  скролл назад по датам, как в Logseq.
- Страницы (`pages/*.md`) с `[[вики-ссылками]]`, `#тегами` и панелью обратных ссылок.
- Задачи — это блоки в стиле `- TODO [#A] текст` с `:LOGBOOK:` (учёт времени),
  свойствами `key:: value`, приоритетами `[#A]/[#B]/[#C]`.
- Кастомный список задач внизу журнала — заменяет logseq-вские `:default-queries`.

## Главные отличия (минусы Logseq, которых здесь нет)
| Logseq | Logtask |
|---|---|
| Electron + ClojureScript, старт секунды, ~1 ГБ ОЗУ, инсталлер 150+ МБ | Tauri 2 + Rust + SolidJS, старт <300 мс, ~100 МБ ОЗУ, бинарник ~14 МБ (deb/rpm ~4 МБ) |
| SQLite/IndexedDB поверх md — двойной источник истины, битые `.transit`, `sync-conflict` (у пользователя их десятки) | md-файлы — единственный источник истины, индекс только в оперативной памяти |
| 24 установленных плагина (awesome-ui, todo-master, todo-plugin…) для базовых вещей | статусы, цвета, группировки задач, шорткаты — в настройках из коробки |
| Datalog для простых фильтров | простой JSON-формат запросов |
| Платная/глючная синхронизация | синхронизация любыми средствами (Syncthing/git) — приложение смотрит только на файлы |

## Документация
1. `docs/01-architecture.md` — стек, слои, модель данных, IPC
2. `docs/02-format.md` — markdown-формат (совместимость с Logseq + расширения: статусы, срочность/важность)
3. `docs/03-ui.md` — окна, виды (лента журнала, канбан задач, матрица Эйзенхауэра), шорткаты
4. `docs/04-roadmap.md` — поэтапный план реализации

Контракт на формат (docs/02) — главный артефакт: он фиксирует, что и как
пишется в `.md`, чтобы граф открывался и в Logseq, и в Logtask.
